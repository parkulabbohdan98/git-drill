
Навчальний репозиторій для вправ з git і GitHub.
Детальний журнал виконаних команд - у [drill-log.md](drill-log.md).

## Що відпрацьовано

- Створення репозиторію, коміти, гілки
- Розв'язання конфліктів злиття вручну
- Різниця між `merge` і `rebase`
- Виправлення помилкових комітів: `reset` проти `revert`
- Відновлення втрачених комітів через `reflog`
- Перенесення незакомічених змін між гілками через `stash`
- Робота з віддаленим репозиторієм: `remote`, `push`, `pull request`
